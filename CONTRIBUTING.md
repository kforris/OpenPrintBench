# Contributing

OpenPrintBench welcomes narrowly scoped, reproducible improvements.

Before opening an issue:

1. Remove model contents, account information, printer serials, local paths,
   and other private data.
2. Include the slicer name and version.
3. Include a minimal input only when its license permits redistribution.
4. State whether the result was planned, sliced, or physically printed.

Before opening a pull request:

1. Read `AGENTS.md`.
2. Add or update tests for changed behavior.
3. Run every command in the required validation section.
4. Keep the change focused; unrelated refactors should use a separate PR.
5. Explain any trademark, license, or fixture provenance concerns.

Security issues should follow [SECURITY.md](SECURITY.md), not a public issue.
